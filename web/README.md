# web

The owner's single-page app: React, TypeScript, Vite. Everything about running
it, the API it talks to, and the design system it follows is in the repository
root [`README.md`](../README.md); this directory carries no setup of its own.

```bash
npm install      # or `make install` from the root, which also installs the backend
npm run dev      # or `make dev` from the root, which also starts the API and the bot
npm test
npm run lint
npm run build
```
