# Documentation home

Project documentation for the AI Payments Assistant. This folder is an Obsidian
vault, but git is the source of truth — Obsidian is only a reading and graph UI
on top of plain markdown files. Every note here is readable as static markdown
in a pull request diff or on the repository web UI.

## Reading this vault

- **In Obsidian:** open `documentation/` as a vault. Config travels with the
  repository, so links, graph view, and attachment handling work on checkout.
- **Anywhere else:** every note is plain markdown with relative links. No
  plugin is required to read or verify it.

## Structure

| Path | Contents |
| --- | --- |
| `index.md` | This note. Entry point to the vault. |
| `conventions.md` | Rules every note in this vault follows. |
| `generated/` | Notes generated by tooling or by an assistant. |
| `assets/` | Images and attachments referenced by notes. |

Two further folders are added once we have content for them: `adr/` for
architecture decision records, and `decisions/` for narrower calls that do not
warrant a full ADR.

## Conventions

Before adding or editing a note, read [Conventions](conventions.md). The rules
there are enforced in CI by `.github/workflows/docs.yml`, and can be run
locally with `./scripts/check-docs.sh`.
